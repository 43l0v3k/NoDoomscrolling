# NoDoomscrolling

Блокировщик коротких видео для Android. Замечает, что открылся экран шортсов, и закрывает его.

Без регистрации, без рекламы. У приложения нет доступа в интернет, ничего никуда не отправляется.

## Что блокируется

| Сервис | Как |
|---|---|
| YouTube Shorts | выходит назад из экрана шортсов |
| Instagram Reels | выходит назад из вкладки Reels |
| TikTok, Likee | возвращает на рабочий стол |

В планах: VK Клипы, Yappy.

Ограничение: рилсы, открытые прямо из ленты Instagram, пока не блокируются.

## Установка

1. Скачай `NoDoomscrolling.apk` из раздела [Releases](../../releases/tag/latest).
2. Установи и открой приложение.
3. Нажми «Специальные возможности» и включи службу NoDoomscrolling.
4. Если Android пишет «ограниченные настройки», открой Настройки → Приложения → NoDoomscrolling, нажми ⋮ и выбери «Разрешить ограниченные настройки». Это защита Android для приложений не из магазина.

## Зачем нужны специальные возможности

Только так Android позволяет программе увидеть, какой экран открыт в других приложениях. NoDoomscrolling смотрит на названия элементов экрана, чтобы узнать шортсы, и не читает ваши сообщения и не сохраняет содержимое экранов. Режим «Диагностика» (выключен по умолчанию) записывает только технические названия элементов, прямо на телефоне.

## Сборка

Проект собирается через GitHub Actions: каждый push в `main` собирает подписанный APK и обновляет релиз `latest`. Нужны Java 17 и Gradle 8.11.
